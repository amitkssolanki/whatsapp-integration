# Portfolio claims and their evidence

Every claim made about this project in its README, case study and portfolio material maps to a row below, with the evidence behind it and a status. The statuses are: **Proven** (observed in real evidence, in the code and its tests, or in CI), **Proven (simulated only)** (covered by specs or the synthetic seed, never observed against Meta), and **Not claimed** (stated here so nobody has to guess). The real evidence is the V1 live run on 2026-08-08 and V2 verification session 1 on 2026-10-06 (one session, the author as the only customer); it is described in `docs/evidence/2026-10-06-verification-session-1.md`.

Evidence that lives only in a private archive (the V1 server log and database dump, with SHA-256 checksums) is named as "private evidence archive". Phone numbers, Meta account ids and the server address are deliberately not reproduced anywhere in this repository.
